## Поток 4. Мультикомандные RFA: кто уже взял в работу (п.6)

**Решение пользователя:** «взято в работу» = эпик этой команды под RFA **входит в утверждённый сценарий** её
команды. Статус в Jira не смотрим.

- Мультикомандная RFA — `backlog_service.issue_is_multi_team` (`backlog_service.py:167-180`); участники —
  `Issue.participating_teams` (+ `Issue.team`).
- Для каждой мультикомандной RFA считать по каждой команде-участнице:
  - `взят` — у команды есть эпик под RFA, включённый (`included_flag`) в её утверждённый сценарий; указать
    название сценария и квартал;
  - `не взят` — эпик есть, но ни в одном утверждённом сценарии команды;
  - `нет эпика` — у команды нет эпика под этой RFA.
  Квартал: утверждённые сценарии любого квартала, кроме завершённых раньше текущего (берём текущий и будущие).
- **Целевые задачи** (`BacklogPage.tsx`): у строки мультикомандной RFA и у строк её эпиков — плашка
  «в работе у K из N». Подсказка — список команд со статусом. Цвет: K = 0 — серый; 0 < K < N — **жёлтый
  (яркий) у строк команд, которые ещё не взяли**, нейтральный у взявших; K = N — зелёный.
- **Сценарий** (`PlanningPage.tsx`, строка — `BacklogAllocRow.tsx`): у строки эпика мультикомандной RFA — та
  же плашка. Над таблицей — предупреждение «⚠ N задач уже взяли соседи, у вас не включены» (строки, где
  эта команда не включила задачу, а другие участники RFA уже взяли) + переключатель «Показать только их».
- Данные отдаёт сервер вместе со строками (одним запросом на страницу, без N+1).

## Поток 5. Фактическая вовлечённость (п.4)

**Формула (решение пользователя):** факт = часы списаний на задачах вида работ «Проекты и развитие» (`project`)
÷ все списанные часы человека за период. Рядом — «списано от нормы» = все списанные ÷ норма (календарь минус
отсутствия, `capacity_service.employee_monthly_capacity` / `employee_quarter_capacity`), чтобы видеть, насколько
цифре можно верить.

- Вид работ задачи — через категорию: списание → задача → категория (с наследованием, `CategoryResolver`) →
  вид работ. Брать тот же путь, что `analytics_service.get_dashboard_norm_work` (:913), не изобретать новый.
- Кто: сотрудники ролей «Аналитик» и «Разработчик» (по роли сотрудника; роль у сотрудника заполнена не у всех —
  без роли не показывать). Команда — по членству на дату списания (правило «часы режутся по дате списания»).
- **Справочник вовлечённости** (`InvolvementDefaultsDrawer.tsx`): у строки роль × команда рядом с заданным
  процентом — «факт N%» за **последний завершённый квартал** (среднее по людям роли: Σ проектных ÷ Σ всех, не
  среднее процентов). Подсказка: квартал, число людей, «списано от нормы M%». Нет данных — прочерк.
- **Отчёт «Фактическая вовлечённость»** — кнопка в справочнике открывает окно/страницу: выбор команды(команд из
  шапки) и квартала; таблица: сотрудник, роль, по месяцам квартала факт %, итог квартала %, списано от нормы %;

базе сумма, время в базе сумма), `perf_slow_request` (детали медленного), `perf_server_snapshot` (минута, CPU/RAM
сервера и процесса, пул). Ревизия `pf01_perf_metrics`, предок — `iv01_clear_frozen_involvement` (при слиянии
перецепится за `wl01_plan_watchlist`).

### 8.3 Экран (Настройки → Администрирование → «Быстродействие», только админ)
- Период: последний час / сутки / 7 дней / 30 дней.
- График: по времени — 95-й процентиль длительности запросов и число медленных поверх загрузки процессора
  сервера и процесса. Подпись-вывод на графике медленной минуты: «сервер загружен на 95%, наш процесс 10%» →
  «похоже, ресурсы съел кто-то другой»; «процесс 90%» → «медленный наш код».
- Таблица «Узкие места»: шаблон пути (с человеческим названием раздела, где получится), вызовов, среднее,
  95-й процентиль, максимум, обращений к базе в среднем, доля времени в базе; сортировка по суммарному
  времени (что сильнее всего тормозит всех).
- Таблица «Медленные запросы»: время, пользователь, раздел, длительность, база, загрузка сервера в ту минуту;
  раскрытие — детали с самыми долгими обращениями к базе.
- Кнопки «Отчёт для разработки» (текстовый файл `.md`: топ узких мест, медленные запросы с деталями, нагрузка
  сервера в эти минуты, вывод «сервер/код») и «Excel» (листы: узкие места, медленные запросы, снимки сервера).
