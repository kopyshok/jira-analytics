# Поток 7 — «Минорные изменения» на «Целевых задачах». План (TDD)

Спека: `docs/superpowers/specs/2026-10-04-q4-improvements-pack-design.md`, раздел «Поток 7».

## Решения
- Новый сервис `app/services/minor_changes.py`, чистое чтение, без commit.
- Минорная задача = эффективная категория (`CategoryResolver.resolve_for_issue`, наследование от родителей)
  относится к категории с видом работ `minor_change`. Кандидаты — открытые (статус-категория не «done»,
  статус не отмена по `is_cancel_like`), не вне охвата, команда задачи из фильтра. Предки подгружаются
  пачками по уровням, чтобы резолвер не делал запрос на каждый шаг вверх.
- Единицы подсчёта (листья): есть оценённые потомки среди минорных — берём детей рекурсивно;
  иначе своя оценка — берём задачу; иначе дети; иначе сама задача.
- Часы по ролям — действующие оценки задачи (`Issue.planned_<роль>_hours`), роли analyst/dev/qa/opo.
  Нет ни одной оценки — «без оценки».
- «Заложено на квартал» — `normed_reserve.team_reserve` за текущий квартал, сумма `planned` по виду `minor_change`;
  нет запаса/правил — `null`.
- Эндпоинт `GET /api/v1/backlog/minor-changes-summary?teams=` (до `/{item_id}`), ответ — блок на команду.
- Фронт: `?minor=1` в адресе, метка-переключатель рядом со «Не в плане», новый компонент
  `MinorChangesCard` (карточки по командам + раскрываемый список), хук и API.

## Шаги
1. Тесты сервиса (категория по наследованию, done/отмена, листья, часы по ролям, команда, запас) → сервис.
2. Тест эндпоинта → роутер.
3. Фронт: API+хук, компонент, переключатель в BacklogPage, build, eslint.
4. Проверка на копии боевой базы, итоговый прогон.
