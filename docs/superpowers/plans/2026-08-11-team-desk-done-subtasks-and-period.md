# План: стол тимлида — выполненные подзадачи, период, память отборов

Спека: [2026-08-11-team-desk-done-subtasks-and-period-design.md](../specs/2026-08-11-team-desk-done-subtasks-and-period-design.md)

## 1. Выборка задач (`app/services/team_desk/query.py`)

`_select_issues` получает окно периода и признак «добирать выполненные подзадачи».

- Фильтр статуса: окно задано → «не закрыта ИЛИ создана в окне ИЛИ закрыта в
  окне»; иначе как сейчас.
- Добор подзадач вторым запросом: тип из справочника подзадач, родитель среди
  уже выбранных, статус в группе «Готово», разработчик из того же состава,
  скрытые статусы исключены. Только когда фильтр статуса вообще применялся.
- `build_overview` пробрасывает новые параметры.

Проверка: `py -3.10 -m pytest tests/test_team_desk_query.py -v`

## 2. Эндпоинт (`app/api/endpoints/team_desk.py`)

Три новых параметра запроса: две даты окна и переключатель подзадач
(по умолчанию включён). Прокидываются в `build_overview`.

Проверка: `py -3.10 -m pytest tests/test_team_desk_endpoint.py -v`

## 3. Профиль пользователя (`app/api/endpoints/users.py`)

Схема отбора стола расширяется пятью полями: режим, две даты, «показывать
просмотренные», «выполненные подзадачи». Хранилище свободное — миграции нет.

Проверка: сохранить и прочитать отбор, значения по умолчанию для старых
пользователей.

## 4. Фронт

- `api/teamDesk.ts` — параметры запроса и тип сохранённого отбора.
- `hooks/useTeamDesk.ts` — новые параметры в ключе запроса.
- `components/teamdesk/DeskFilters.tsx` — переключатель на три положения, выбор
  дат в положении «За период», переключатель подзадач (гаснет в «Все задачи»).
- `pages/TeamDeskPage.tsx` — состояние шапки переезжает в профиль, период по
  умолчанию — текущий квартал.

Проверка: `npm run lint` + `npm run build`.

## 5. Тесты

`tests/test_team_desk_query.py`: закрытая подзадача под открытым родителем
(видна / не видна, счётчики не поехали), подзадача-сирота не добирается,
окно периода (закрыта внутри / до окна / создана внутри / старая открытая).
