# Аналитика трудозатрат

Раздел «Аналитика» (меню «Обзор» → «Аналитика», заголовок страницы «Иерархический отчёт по часам») показывает, кто, сколько и над чем работал за период. Это главный разрез по факту работы: команда → роль → сотрудник → вид работ → категория → задача. Все цифры — фактические списания часов из Jira за выбранный период по выбранным командам.

---

## 1. Зачем раздел

В Jira ежедневно копятся сотни ворклогов от десятков сотрудников. Сводных отчётов по часам в Jira нет — она показывает либо одну задачу, либо одного сотрудника. Этот раздел собирает все списания за период в один отчёт и даёт пройти по иерархии сверху вниз: команда целиком → роль → сотрудник → вид работ → категория → задача → отдельные ворклоги.

Главные вопросы, на которые отвечает раздел:

- Сколько часов команда отработала за квартал и сколько было запланировано?
- Кто перерабатывает, кто недогружен?
- Куда уходит время — в проекты, во встречи, в техдолг, в сопровождение?
- На каких задачах конкретного сотрудника ушли часы по конкретному виду работ?
- Списываются ли сотрудники моей команды на чужие задачи (за периметр команды)?
- Какие задачи ещё без категории и куда из-за этого «провалились» часы?

Цифры виджетов дашборда раскладываются именно здесь — по клику на них.

## 2. Когда сюда заходить

- Утренний разбор перегруза — кто из сотрудников зашкаливает за план, в каких видах работ и категориях.
- Подготовка отчёта руководству за квартал — сколько часов в каждой категории, кто во что вкладывался.
- Когда на дашборде подозрительная цифра — нажать на неё и провалиться сюда.
- Расследование «куда у Иванова ушло 180 часов» — открыть его строку, дойти до задач, открыть ворклоги.
- Проверка чужих списаний — сотрудники списались на задачи других команд, надо понять масштаб.
- План/факт по виду работ — сколько из запланированных на «Проекты и развитие» часов реально ушло туда.
- Разбор задач без категории — найти их в отчёте и сразу проставить категорию.

## 3. Элементы интерфейса

Сверху — плитки итогов, под ними слева — список команд, справа — фильтры и иерархическая таблица. В шапке раздела — уточнение дат, переключатели «Ворклоги» и «Иерархия», кнопки «Настройка отчёта» и «Экспорт XLSX». Команды и период берутся из шапки приложения. Любая смена фильтра сразу перестраивает и плитки, и таблицу.

### 3.1. Период: шапка приложения и уточнение дат

Основной период выбирается в шапке приложения: год, квартал («Q1 (янв-мар)» … «Q4 (окт-дек)») и месяц («Весь Q» или конкретный месяц). Этот выбор общий для всех разделов и хранится в вашем профиле.

В шапке самого раздела есть поле «Уточнить с — по» — обычный диапазон дат. Используйте его, когда нужен не весь квартал, а отрезок: прошлая неделя, конкретный спринт. Уточнение перекрывает период из шапки только в этом разделе и только до ухода со страницы — оно не сохраняется и не попадает в ссылку.

Важно: план при уточнении дат не пересчитывается — он остаётся планом квартала (или месяца) из шапки. Для узкого отрезка сравнивайте факт, а не процент выполнения.

### 3.2. Переключатель «Ворклоги»

Определяет, что происходит по клику на строку задачи:

- **drawer** (по умолчанию) — справа открывается карточка задачи: контекст, категория, ворклоги (см. 3.11).
- **inline** — под задачей раскрывается таблица её ворклогов за период: «Когда», «Кто», «Часы», «Комментарий».

Переключатель не запоминается: после перезагрузки страницы снова стоит «drawer».

### 3.3. Плитки итогов

Над таблицей пять плиток с итогами за период с учётом всех фильтров и выбранной команды в списке слева:

| Плитка | Что показывает |
|--------|---------------|
| Σ Часов факт | Сумма всех списаний в отчёте |
| Σ Часов план | Сумма планов всех сотрудников, попавших в отчёт, по всем видам работ |
| % Выполнения | Факт / план. До 70% — зелёный, от 70% до 110% — жёлтый, больше 110% — красный |
| Сотрудников | Сколько сотрудников что-то списали |
| Чужих часов | Часы на задачи чужих команд и их доля от факта. Оранжевый, если такие часы есть |

### 3.4. Список команд

Карточка «Команды» слева: пункт «Все команды» и команды с итогом часов («… ч»). Сотрудники без команды собраны в строку «Без команды» — она появляется, только если в шапке не выбрана ни одна команда.

- При открытии раздела выбрана **первая команда** из фильтра шапки. Если в шапке выбрано несколько команд, а нужны все сразу — нажмите «Все команды».
- Клик по команде пересчитывает весь отчёт только по ней: плитки, таблицу, выгрузку. Список после этого показывает только выбранную команду — вернуться ко всем можно через «Все команды».
- Когда выбрана одна команда, уровень «Команда» в таблице пропадает — значение всё равно одно.

### 3.5. Иерархическая таблица

Уровни группировки сверху вниз: **Команда → Группа → Роль → Сотрудник → Вид работ → Категория → Задача**. Уровень «Группа» (группа внутри команды) по умолчанию скрыт — включается в настройке отчёта (см. 3.6). Каждая строка группы раскрывается по клику, итоги считаются по всему, что под ней. Строки внутри каждого уровня идут по убыванию фактических часов; сортировки по колонкам нет.

Раскрытые строки запоминаются в браузере — при следующем заходе дерево откроется так же.

Колонки таблицы:

| Колонка | Что показывает |
|---------|---------------|
| Группа / Задача | Название группы или ключ и название задачи с метками (см. 3.8) |
| Часы факт | Сумма списаний под строкой. Цвет цифры — по проценту выполнения плана, по тем же порогам, что и плитка |
| Часы план | План «сотрудник × вид работ». На строках групп — сумма таких планов, попавших в строку |
| % план | Факт / план |
| % в группе | Доля строки в её непосредственной родительской строке |
| % от итога | Доля строки от общего факта отчёта |
| Ворклогов | Сколько списаний под строкой |
| Задач | Сколько разных задач |
| Сотр. | Сколько сотрудников списывали часы под строкой |
| Ср.мин | Средняя длина одного списания, в минутах |

Колонки «Группа / Задача» и «Часы факт» видны всегда, остальные включаются и выключаются в настройке отчёта (см. 3.7).

Что есть на строках разных уровней:

- **Роль** — цветная точка роли.
- **Сотрудник** — кружок с инициалами в цвете роли.
- **Вид работ** — стрелка «Тематический отчёт»: открывает тематический отчёт по этому виду работ с тем же периодом и командами.
- **Задача** — ключ-ссылка (открывает задачу в Jira в новой вкладке), статус, метка «Чужая», название. У задач категорий «Квартальные задачи» и «Архив целевых задач» есть стрелка «Открыть страницу проекта» — ведёт в карточку проекта.

### 3.6. Настройка отчёта: группировка

Кнопка «Настройка отчёта» открывает окно из трёх секций: «Группировка», «Столбцы», «Визуализация».

В секции «Группировка»:

- **Четыре готовых набора**: «Стандарт» (команда → роль → сотрудник → вид работ → категория → задача), «По людям» (сотрудник → категория → задача), «По категориям» (категория → вид работ → задача), «По видам работ» (вид работ → категория → задача). Выбранный набор подсвечен.
- **Список «Активные уровни»** — уровни перетаскиваются за значок слева, порядок меняется (например, сначала категория, потом сотрудник).
- **Глазок** («Скрыть уровень» / «Показать уровень») — убирает уровень в список «Скрытые»; его итоги собираются на уровень выше. Так же включается уровень «Группа».

Уровень «Задача» скрыть нельзя. Держите его последним: уровни, перетащенные ниже «Задачи», в таблице не показываются. После ручной перестановки или скрытия подсветка набора снимается. Настройки сохраняются сразу и за вашим пользователем на сервере — у каждого аналитика своя раскладка.

### 3.7. Настройка отчёта: столбцы и полоска

Секция «Столбцы» — галочки по необязательным колонкам: «Часы план», «% план», «% в группе», «% от итога», «Ворклогов», «Задач», «Сотрудников», «Ср. минут». По умолчанию включены все, кроме «% от итога». Набор сохраняется за вашим пользователем и влияет и на таблицу, и на выгрузку.

Секция «Визуализация» — галочка «Полоска заполнения в колонке «Часы факт»» (по умолчанию включена). Тонкая полоса под цифрой показывает долю строки в родительской строке, а на верхнем уровне — долю от общего итога. Помогает на глаз сравнивать соседние строки. На строках задач полоски нет.

### 3.8. Метки на строках

- **Статус задачи** — цветной тег со статусом из Jira.
- **«Чужая»** (оранжевая) — задача принадлежит не той команде, за которую считается сотрудник: он списался на неё «за периметр».
- **«Команда: …»** — под чужой задачей: к какой команде она относится, с цветным квадратом (цвет постоянный для каждой команды).
- **Оранжевый чип «⚠ N · Mч · X%»** на строках групп — сколько чужих задач под строкой, сколько на них часов и какая это доля от факта строки. Подробности — во всплывающей подсказке. Чип появляется, только если чужие задачи есть.
- **Приглушённый курсив** — в режиме «Иерархия» так показаны родители без собственных часов (см. 3.12).

### 3.9. Фильтры над таблицей

Над таблицей четыре фильтра:

- **«Сотрудник»** — оставить одного сотрудника, с поиском по имени.
- **«Поиск задачи»** — по ключу или части названия; срабатывает по Enter или по значку лупы.
- **«Вид работ»** — оставить списания одного вида работ.
- **«Категория»** — оставить задачи одной категории (своей или унаследованной от родителя). Чужие задачи с этой категорией тоже попадут, даже если в отчёте они лежат в виде работ «Прочие / Чужие задачи».

Фильтры записываются в адресную строку — ссылку можно переслать коллеге. Период и команды у коллеги возьмутся из его собственной шапки; уточнение дат и выбор команды в списке слева в ссылку не попадают.

### 3.10. Переход из других разделов

В аналитику можно провалиться по клику — раздел откроется с проставленным фильтром:

- **Дашборд → «Нормированные работы»**: клик по сотруднику — фильтр по сотруднику; клик по строке вида работ у сотрудника — сотрудник и вид работ; значок «Тематический отчёт» открывает тематический отчёт.
- **Дашборд → «Ворклоги по категориям задач»**: клик по плитке категории — фильтр по категории; клик по сотруднику в блоке «Последний ворклог сотрудника» — фильтр по сотруднику.
- **Карточка проекта → «Структура трудозатрат»**: клик по категории — фильтр по категории.
- **Карточка проекта → «Участники»**: клик по сотруднику — фильтр по сотруднику.
- **Карточка проекта → «Топ-3 задачи по трудозатратам»**: открывает аналитику без фильтра.

При переходе из карточки проекта отчёт **не ограничивается этим проектом** — показываются все часы по категории или сотруднику за период. Переход заменяет фильтры, которые стояли в адресной строке; период и команды из шапки остаются. Настройки группировки и колонок не меняются.

### 3.11. Карточка задачи

Открывается справа по клику на строку задачи, когда переключатель «Ворклоги» стоит в положении «drawer». Строки-родители в режиме «Иерархия» по клику раскрываются, а не открывают карточку.

- **Шапка** — ключ задачи (ссылка в Jira), статус, название. Кнопка «← назад» появляется, когда вы перешли внутри карточки к другой задаче; «×» — закрыть.
- **«Контекст»** — цепочка родителей до самого верха, каждая строка кликабельна и открывает карточку родителя. У ближайшего родителя — значок «+N соседей ▾»: список «Соседние задачи» с переходом к любой из них. Ниже — таблица «Подзадачи» с колонками «Ключ», «Название», «Статус», «Категория», «В анализ»: категорию и галочку можно менять прямо здесь, они сохраняются сразу. Если подзадач нет — «У задачи нет подзадач».
- **«Категория и анализ»** — текущая категория (с пометкой «унасл.», если она досталась от родителя) и выбор новой; галочка «Учитывать в анализе»; переключатель «Применить ко всему поддереву (N задач)» — категория ставится на задачу и её потомков. Кнопки «Отмена» и «Сохранить». Архивные категории сами снимают галочку «Учитывать в анализе». Для задач-контейнеров выводится предупреждение «Это контейнер. Категории ставятся детям, не самому контейнеру.» и выбор категории недоступен.
- **«Ворклоги за период»** — даты периода и таблица «Когда», «Кто», «Часы», «Комментарий». Здесь все списания по задаче за период от всех сотрудников, а не только от сотрудника, в строке которого вы кликнули.

После сохранения категории отчёт пересчитывается сам.

### 3.12. Переключатель «Иерархия»

В шапке раздела, рядом с переключателем «Ворклоги». По умолчанию выключен — задачи внутри категории идут плоским списком по убыванию часов.

Когда включён, задачи внутри категории выстраиваются деревом: для каждой задачи достраивается цепочка родителей до самой верхней задачи без родителя — так же, как в разделе «Категории задач». Одинаковые родители склеиваются в один узел.

Как читать строки дерева:

| Строка | Что показывает |
|--------|---------------|
| Обычная задача | свои часы |
| Родитель | сумму часов всей ветки под ним внутри этой группы |
| «Собственные списания» | часы, списанные прямо на родителя (встречи, анализ на эпике) — вынесены отдельной подстрокой, чтобы не растворяться в сумме ветки |

Родители, у которых нет своих часов, показываются приглушённым курсивом — они нужны только чтобы показать, откуда задача. Если родитель принадлежит другой команде или другой категории, он всё равно попадает в дерево — цепочка не обрывается.

Итоги команды, роли, сотрудника, вида работ и категории при включении не меняются — те же часы, просто разложены по дереву. Колонка «Задач» у родителя считает все задачи ветки. Переключатель не запоминается: при перезагрузке страницы он снова выключен.

### 3.13. Экспорт XLSX

Кнопка «Экспорт XLSX» в шапке скачивает Excel-файл с текущим срезом: учитываются период, уточнение дат, выбранная в списке команда, группы из шапки и все фильтры.

Файл — плоский список задач: по строке на каждое сочетание «сотрудник × вид работ × категория × задача». Колонки: «Команда», «Группа», «Роль», «Сотрудник», «Вид работ», «Категория», «Ключ», «Заголовок», «Тип», «Статус», «Часы факт» и дальше — те необязательные колонки, которые включены у вас в настройке («Часы план», «% план», «% от итога», «Ворклогов», «Задач», «Сотрудников», «Ср.мин»). Колонки «% в группе» в файле нет. Порядок и скрытие уровней группировки на файл не влияют — все уровни всегда идут отдельными колонками. План на строках задач в файле не заполняется.

Если включён переключатель «Иерархия», выгрузка повторяет дерево: строки идут в том же порядке, ключ задачи сдвинут отступом по уровню вложенности, добавляется колонка «Уровень», а сам лист сворачивается и разворачивается стандартной группировкой Excel.

## 4. Откуда цифры

- **Часы** — ворклоги Jira, загруженные синхронизацией (раздел «Синхронизация»; перечитать ворклоги за прошлые даты — вкладка «Дополнительно» → «Обновить ворклоги с даты»). Часы берутся по дате списания.
- **Команда сотрудника и периоды участия** — из «Настройки → Команды и группы». Если в шапке выбраны команды, в отчёт попадают только те списания, которые сделаны в дни, когда сотрудник состоял в одной из этих команд. Переведённый или выбывший сотрудник виден в старой команде за время участия, его более поздние часы уходят в новую команду. В строке «Команда» сотрудник показывается под основной командой, если она выбрана в шапке, иначе — под первой совпавшей. Если в шапке команды не выбраны, в отчёт идут все сотрудники под своей основной командой на конец периода.
- **Роль** — из карточки сотрудника (раздел «Ресурсы»). У сотрудника одна роль; без роли — строка «Без роли».
- **Вид работ** — определяется категорией задачи: у каждой категории в «Настройки → Категории работ» указан её вид работ. Отдельного поля в Jira для этого нет.
- **Категория** — из раздела «Категории задач». Если у задачи нет своей категории, она наследуется от ближайшего родителя.
- **Задачи без категории** в отчёт попадают — в вид работ «Не указана категория/вид работ», категорию «Без категории». Туда же уходят задачи, чья категория не связана ни с одним видом работ (тогда категория видна со своим названием).
- **Задачи, исключённые из анализа** (архивные категории или снятая галочка «Учитывать в анализе»), тоже не пропадают — они собраны в вид работ «Исключено из анализа», чтобы сумма часов сотрудника совпадала с тем, что он списал в Jira.
- **Чужие задачи** — задача считается чужой, если ни основная, ни участвующая команда задачи (поле команды в Jira, «Настройки → Поля Jira») не совпадает с командой, за которую считается сотрудник. Задача без команды для сотрудника с командой тоже чужая. Чужие задачи без ручной категории отчёт относит к виду работ «Прочие / Чужие задачи»; если категорию задаче поставили вручную — задача остаётся в своём виде работ, но с меткой «Чужая».
- **Группа** — группа внутри команды, к которой отнесена задача (см. раздел 9).
- **План** — рабочие часы сотрудника за квартал или месяц из шапки (норма за вычетом отсутствий по производственному календарю), разложенные по видам работ процентами: правила обязательной загрузки из утверждённого сценария квартала выбранных команд (если такого нет — общий шаблон правил по ролям) и личные проценты сотрудника, если они заданы. Остаток после всех процентов отдаётся виду работ «Проекты и развитие». Если сотрудник был в команде не весь период, план режется пропорционально времени участия по месяцам.
- **План в строках таблицы** — считается по парам «сотрудник × вид работ», попавшим в строку. Вид работ, по которому у сотрудника в отчёте нет ни одного списания, в таблицу не попадает — поэтому сумма плана по строкам может быть меньше плитки «Σ Часов план», которая берёт план по всем видам работ.
- **% в группе** — доля строки в её непосредственной родительской строке. Например, у сотрудника под ролью — его доля в роли, у задачи — доля в категории.
- **% от итога** — доля строки от общего факта всего отчёта с учётом фильтров.

## 5. Типовые задачи

### Сценарий А: утренний разбор перегруза

1. Открыть «Аналитику».
2. В шапке приложения проверить команду (или несколько) и период — текущий квартал.
3. Если в шапке несколько команд — в списке слева нажать «Все команды».
4. Плитка «% Выполнения» — общий статус.
5. «Настройка отчёта» → «Стандарт» (или «По людям», если роль не нужна).
6. Раскрыть роли и пройтись по сотрудникам: красная цифра в «Часы факт» или «% план» — перерасход.
7. Раскрыть перегруженного сотрудника, посмотреть, в каком виде работ и категории перерасход.
8. Раскрыть категорию — увидеть конкретные задачи и открыть карточку задачи с ворклогами.

### Сценарий Б: отчёт по сотруднику за спринт

1. В фильтре «Сотрудник» выбрать человека.
2. В поле «Уточнить с — по» задать даты спринта.
3. «Настройка отчёта» → «По категориям» — видно, в какие категории и виды работ ушли часы.
4. При необходимости включить «Иерархия», чтобы видеть задачи под своими эпиками.
5. «Экспорт XLSX» — отдать руководителю.

### Сценарий В: настроить свой набор колонок

1. Кнопка «Настройка отчёта».
2. Секция «Столбцы» — снять ненужное (например, «Ср. минут», «Сотрудников»).
3. Оставить «Часы план», «% план», «% от итога» — для компактного вида.
4. Секция «Визуализация» — оставить или снять «Полоска заполнения в колонке «Часы факт»».
5. Закрыть окно — настройка уже сохранена за вашим пользователем.

### Сценарий Г: провалиться с дашборда

1. На дашборде в виджете «Ворклоги по категориям задач» видна большая доля «Технического долга».
2. Клик по плитке категории — открывается аналитика с фильтром по этой категории.
3. В таблице — сотрудники, которые списывали часы в техдолг.
4. Раскрыть сотрудника → посмотреть, какие именно задачи.
5. Клик по строке задачи (переключатель «Ворклоги» в положении «drawer») → справа карточка с контекстом и ворклогами.
6. Перейти в саму задачу — клик по ключу в шапке карточки.

### Сценарий Д: посмотреть чужие списания

1. Плитка «Чужих часов» оранжевая — есть списания за периметр команды.
2. Раскрыть вид работ «Прочие / Чужие задачи» у сотрудников или найти оранжевые чипы «⚠» на строках.
3. На строках задач — метки «Чужая» и под ними название команды-владельца.
4. Если работа на чужую команду законная — добавить сотрудника во вторую команду («Настройки → Команды и группы») или поставить задаче категорию вручную. Если нет — обсудить с сотрудником.

### Сценарий Е: разобрать задачи без категории

1. Найти в таблице вид работ «Не указана категория/вид работ» (удобнее с набором «По видам работ»).
2. Раскрыть его до задач, кликнуть задачу — откроется карточка.
3. В блоке «Категория и анализ» выбрать категорию, при необходимости включить «Применить ко всему поддереву», нажать «Сохранить».
4. Отчёт пересчитается — часы уйдут в нужный вид работ.

## 6. Ограничения

- **При открытии выбрана первая команда из шапки.** Чтобы увидеть все выбранные команды вместе — «Все команды» в списке слева.
- **План не следует за уточнением дат.** При узком диапазоне «с — по» план остаётся квартальным (или месячным), процент выполнения в этом случае не показателен.
- **План на строке задачи** — это план всего вида работ сотрудника, а не план задачи. Процент выполнения на уровне задач не показателен.
- **Сумма плана в таблице** может быть меньше плитки «Σ Часов план» — в таблицу не попадают виды работ, по которым у сотрудника нет списаний.
- **Глобальный фильтр команды действует до выборки.** Если убрать команду из фильтра — её часы исчезнут везде, включая «Чужие». Чужими считаются задачи относительно «своих» сотрудников, а не наоборот.
- **Чужие задачи** определяются по полю команды из Jira. Если поле не настроено или не заполнено, задача считается чужой для любого сотрудника с командой.
- **Уточнение дат** «с — по» перекрывает период из шапки, но не отменяет фильтр команды; оно не сохраняется и не попадает в ссылку.
- **Готовые наборы группировки** перезаписывают и порядок, и видимость уровней. Своя раскладка при этом теряется — запомните её, прежде чем нажимать набор.
- **Переход с карточки проекта** не ограничивает отчёт проектом — показываются все часы по категории или сотруднику за период.
- **Ворклоги в карточке задачи** — все списания по задаче за период, от всех сотрудников, независимо от строки, из которой открыта карточка.
- **Режим «Иерархия»** строит дерево внутри категории, а не поверх всего отчёта: уровни выше остаются как есть. Состояние переключателя не сохраняется между визитами, кнопки «развернуть всё» нет.

## 7. Частые проблемы

| Симптом | Причина | Что делать |
|---------|---------|------------|
| Цифры в аналитике не совпадают с дашбордом | Разный период, в списке слева выбрана одна команда или стоит фильтр в адресной строке | Сверить период в шапке, нажать «Все команды», снять фильтры |
| В отчёте только одна команда, хотя в шапке выбрано несколько | При открытии выбирается первая команда из шапки | Нажать «Все команды» в списке слева |
| Сменил команду в шапке, а отчёт показывает прежнюю | Выбор в списке слева остался от прошлой команды | Нажать «Все команды» или обновить страницу |
| Нажал «Без команды» — отчёт пустой, список команд пропал | По этой строке отчёт не строится | Обновить страницу |
| Часть часов лежит в «Не указана категория/вид работ» | У задач нет категории или категория не связана с видом работ | Проставить категорию (в карточке задачи или в «Категориях задач»); проверить связку в «Настройки → Категории работ» |
| Часть часов в «Исключено из анализа» | Задачи в архивных категориях или со снятой галочкой «Учитывать в анализе» | Это нормально; если задача исключена по ошибке — вернуть галочку в карточке задачи |
| Не вижу нужной колонки | Колонка скрыта в ваших настройках | «Настройка отчёта» → «Столбцы» → включить |
| Галочка «Ср. минут» включена, а колонки «Ср.мин» в таблице нет | Сейчас эта колонка в таблице не выводится | Средняя длина списания есть в выгрузке XLSX |
| Не вижу уровня «Группа» | Он скрыт по умолчанию | «Настройка отчёта» → «Группировка» → глазок у «Группа» |
| Таблица пустая, «Нет данных за выбранный период» | Фильтр команды отрезает всё, период вне данных или слишком узкий фильтр | Расширить фильтр в шапке или сменить период; если стоят фильтры — кнопка «Сбросить фильтры» |
| План = «—» | У сотрудника нет рабочих часов в периоде или нет правил загрузки | Проверить нормы и отсутствия в «Ресурсах», правила обязательной загрузки в сценарии |
| Процент выполнения странный при уточнении дат | План не режется по датам уточнения | Сравнивать факт; для плана — смотреть весь квартал или месяц |
| Открыл аналитику с карточки проекта, а часов больше, чем в проекте | Проект в фильтр не передаётся | Сузить фильтром «Поиск задачи» или смотреть трудозатраты в карточке проекта |
| «% в группе» = 100% у всех строк | В группе одна строка или промежуточные уровни скрыты | Это нормально — процент считается от непосредственного родителя |
| После перетаскивания уровней набор перестал подсвечиваться | Ручная перестановка — это уже своя раскладка | Нажать нужный набор снова — он перезапишет порядок |
| Экспорт XLSX отдаёт «не то» | Выгрузка берёт текущие фильтры, команду из списка слева и включённые колонки | Перед выгрузкой проверить фильтры, команду и колонки |

## 8. Связанные разделы

**Откуда приходят данные:**

- **Синхронизация** — без свежей синхронизации в аналитике не будет новых ворклогов и задач из Jira. Перечитать ворклоги за прошлые даты — вкладка «Дополнительно».
- **Категории задач** — категория задачи определяет вид работ, в который пойдут её часы.
- **Ресурсы** — роли сотрудников, нормы, отсутствия. Отсюда рабочие часы для плана.
- **Сценарии** — правила обязательной загрузки утверждённого сценария задают проценты плана по видам работ.
- **Настройки → Команды и группы** — состав команд, основная команда, периоды участия, группы внутри команды.
- **Настройки → Категории работ** и **Виды работ** — справочник категорий и связка категория ↔ вид работ.
- **Настройки → Поля Jira** — какое поле Jira считается командой задачи.
- **Настройки → Производственный календарь** — рабочие дни для плана.
- **Шапка приложения** — команды, группы и период.

**Куда ведут переходы:**

- **Дашборд** — виджеты «Нормированные работы» и «Ворклоги по категориям задач» открывают аналитику с фильтром.
- **Тематический отчёт** — стрелка на строке вида работ открывает его по этому виду работ.
- **Проекты** — стрелка на задачах-проектах открывает карточку проекта; карточка проекта тоже открывает аналитику.
- **Экспорт XLSX** — снимок отчёта для отправки руководству.

Это самый «нагруженный» отчёт в системе. Любая аналитическая претензия («у нас всё плохо с техдолгом», «Иванов недогружен», «команда выпиливает чужие задачи») проверяется и подтверждается именно здесь — провалом по дереву до конкретной задачи и конкретного ворклога.

## 9. Группы внутри команды

Если команда разделена на группы («Настройки → Команды и группы»), в фильтре команд в шапке
появляется второй уровень — «Группы». Отчёт при выборе группы считает только её
работы: часы попадают в ту группу, к которой отнесена задача, — даже если их
списал человек из соседней. Пункт «Без группы» показывает то, что к группам
ещё не отнесли, поэтому сумма по группам всегда равна итогу команды.

Чтобы видеть группы строками таблицы, включите уровень «Группа» в «Настройка
отчёта» → «Группировка». Задачи, не отнесённые ни к одной группе, собираются в
строку «Без группы».

Над отчётом появляется строка «Переток внутри команды»: по каждой группе —
«−N ч к соседям» (часы её людей, отработанные на задачах соседних групп) и
«+N ч от них» (часы соседей на её задачах). Считается по дню списания часов и по
группе, в которой сотрудник в этот день числится: если он поделён между
группами или недавно переведён, смотрят именно на дату конкретного ворклога, а
не на его текущую группу. Работа человека в любой из его собственных групп на
эту дату перетоком не считается — только работа за пределами его групп.
Помощь извне считается отдельно и на группы не реагирует: граница «свои —
чужие» остаётся на уровне команды.

В xlsx-выгрузке рядом с командой есть колонка «Группа».
