# Отчёт по видам работ

Раздел «Тематический отчёт» (меню «Обзор» → «Тематический отчёт») берёт фактические часы по задачам одного вида работ за выбранный период и показывает, на какие **темы** они ушли. Темы живут в словаре вида работ: ИИ относит каждую задачу к подходящей теме по её смыслу, а для непохожих задач предлагает новые темы-кандидаты.

Раздел целиком построен на ИИ. Если ИИ выключен администратором, вместо отчёта показывается сообщение «Тематический отчёт выключен администратором».

---

## 1. Зачем раздел

Аналитика и дашборд показывают «сколько часов на сотрудника / на категорию / на вид работ». Этот раздел отвечает на другой вопрос: **«на какие содержательные направления ушло время внутри вида работ»**. Не «Сопровождение и консультация» целиком, а «обмены данными», «закрытие периода», «права доступа» — темы, которые выделяются из текста самих задач.

Применение:
- Готовим квартальный отчёт руководителю — нужна одна страница «куда ушёл квартал».
- Подозреваем, что много часов уходит на «невидимое сопровождение», а не на квартальные цели — хотим увидеть это явно.
- Хотим сравнить, сколько направление получило в одном квартале и в другом.
- Нужно понять, есть ли «пожарные темы», которые незаметно растут.

Этот отчёт **не** заменяет Аналитику. Аналитика — иерархия «команда → роль → сотрудник → вид работ → категория → задача → ворклог». Тематический отчёт — другой угол: «тема → задачи в теме». Они дополняют друг друга.

---

## 2. Когда сюда заходить

- Перед квартальным или полугодовым отчётом руководству — взять одну страницу с темами и ИИ-сводкой.
- Когда непонятно, на что ушло время команды, а в Аналитике видно только «много мелких задач».
- После большой синхронизации — посмотреть, появились ли новые темы-кандидаты.
- Когда нужен PDF — страница «PDF для руководства» открывается в новой вкладке и печатается через браузер.
- Раз в квартал — навести порядок в словаре тем: принять кандидатов, слить дубли, отправить устаревшее в архив.

## 3. Элементы интерфейса

| № | Элемент | Что показывает |
|---|---------|----------------|
| 1 | Заголовок «АНАЛИТИКА / Тематический отчёт» | Где вы находитесь |
| 2 | Период (в шапке приложения) | Год + квартал + при необходимости месяц — общий выбор для всех разделов |
| 3 | Фильтр команд (в шапке приложения) | Какие задачи попадают в отчёт (см. раздел 4) |
| 4 | Выбор вида работ + кнопка «Применить» | Переключение между видами работ |
| 5 | Плашка свежести («Свежий» / «Устарел (словарь обновлён)» / «Нет данных») | Состояние показанного отчёта; во всплывающей подсказке — когда он построен |
| 6 | Кнопка «Словарь тем» | Справочник тем: активные, архивные, кандидаты |
| 7 | Кнопки «Пересчитать», «XLSX», «PDF для руководства» | Построение заново и выгрузки |
| 8 | ИИ-сводка | Главный вывод по отчёту одной фразой и служебная строка под ней |
| 9 | Плитки «Часов», «Тем», «Задач», «Сотрудников» | Итоги отчёта |
| 10 | Кольцевая диаграмма «Распределение тем» | Пять самых крупных тем и «Другое»; клик подсвечивает тему в таблице |
| 11 | Карточка «Рекомендация» | Совет ИИ и «Ожидаемый эффект»; если совета нет — «Рекомендаций нет» |
| 12 | Панель кандидатов | Темы, которые ИИ предложил, но которых ещё нет в словаре |
| 13 | Управление группировкой | Готовые наборы, строка «Порядок:», сохранённые макеты |
| 14 | Таблица тем и задач | Темы с раскрытием до задач; клик по ключу — карточка задачи |
| 15 | Блок «Требуют ручной классификации» | Задачи, которые ИИ не смог разобрать |

Справка по разделу открывается кнопкой «Справка» в шапке приложения.

### 3.1. Выбор вида работ

Вид работ — это строка справочника «Настройки → Виды работ» («Проекты и развитие», «Сопровождение и консультация», «Технический долг» и т. д.). В отчёт попадают задачи, чья категория относится к этому виду работ («Настройки → Категории работ»). У каждого вида работ свой словарь тем.

Выбрать вид работ в списке → нажать «Применить». Без «Применить» выбор не срабатывает — так отчёт не перестраивается на каждый щелчок. Последний выбранный вид работ запоминается в этом браузере и открывается при следующем заходе. Стрелка «Тематический отчёт» в Аналитике и значок на дашборде открывают раздел сразу с нужным видом работ.

### 3.2. Плашка свежести и автоматический пересбор

- **«Свежий»** — отчёт построен по текущему словарю тем.
- **«Устарел (словарь обновлён)»** — после построения показанного отчёта словарь меняли. Цифры показаны как были; нажмите «Пересчитать» или обновите страницу.
- **«Нет данных»** — отчёт не удалось получить.

Во всплывающей подсказке у плашки — дата и время построения («Обновлён: …»).

Готовый отчёт сохраняется и показывается всем, кто смотрит тот же вид работ за тот же период с тем же набором команд. При открытии сервис проверяет, есть ли такой отчёт и не устарел ли он: если отчёта за этот период ещё нет, после построения менялись задачи (прошла синхронизация, правили категории) или менялся словарь тем, отчёт **строится автоматически**. В этом случае страница грузится заметно дольше обычного, окна с прогрессом при этом нет.

Если отчёт получить не удалось, а словарь тем пуст, вместо отчёта показывается экран «Тематический отчёт ещё не построен» с кнопкой «Построить первый отчёт».

### 3.3. ИИ-сводка

Карточка с бирюзовой полосой слева. Это **главная фраза** ИИ по выбранному периоду — одна строка; если она длинная, полностью видна во всплывающей подсказке. Под фразой — служебная строка: «Модель: …», «N задач, M ч», «Промпт vN» и метка «AI» или «шаблон».

«Шаблон» — ИИ не ответил, и вместо сводки стоит короткая фраза из итогов («Всего N ч / M задач.»). Рядом появляется пояснение «Нарратив построен по шаблону — AI-сводка недоступна». Это не ошибка отчёта, но и не настоящая сводка. Если отчёт ещё не строился — «AI-сводка появится после первого расчёта».

### 3.4. Плитки

Четыре числа: «Часов» — сумма часов по всем задачам отчёта, «Тем» — сколько тем словаря получили задачи, «Задач» — сколько задач с часами за период, «Сотрудников» — сколько разных людей списывали часы на эти задачи (включая людей из других команд, см. раздел 4).

### 3.5. Распределение тем

Кольцевая диаграмма показывает пять самых крупных тем по часам, остальные темы собраны в «Другое». В центре — все часы отчёта. Справа — те же строки списком с полоской и подписью «N ч (X%)».

В центре стоят часы всех задач отчёта, включая задачи без темы (они лежат в кандидатах) — поэтому проценты тем могут в сумме не дать 100%.

Клик по сегменту или строке списка раскрывает эту тему в таблице, прокручивает к ней и подсвечивает на две секунды. Подсветка работает, когда таблица сгруппирована по темам. Если принятых тем ещё нет, вместо диаграммы — «Темы ещё не приняты» с подсказкой открыть «Словарь тем» → «Кандидаты».

### 3.6. Рекомендация и кандидаты

- **«Рекомендация»** — карточка с жёлтой полосой слева: что ИИ советует по итогам отчёта, и строка «Ожидаемый эффект». Если совета нет — «Рекомендаций нет».
- **Кандидаты** — панель «N кандидатов» появляется, если ИИ предложил темы, которых нет в словаре. На мини-карточках — название, «N ч · M задач» и до пяти ключей задач. Показаны первые пять; дальше — «и ещё N Просмотреть всех». Кнопка «Просмотреть всех кандидатов» открывает «Словарь тем» на вкладке «Кандидаты», где кандидата можно принять, слить с темой или игнорировать (см. 3.11). Кандидат «Другое» — задачи, для которых ИИ не предложил названия.

### 3.7. Управление группировкой

Сверху — пять готовых наборов:

| Набор | Уровни |
|-------|--------|
| «По темам» | тема → задача (по умолчанию) |
| «По сотрудникам» | сотрудник → тема → задача |
| «По командам» | команда → сотрудник → задача |
| «По ролям» | роль → сотрудник → задача |
| «По проектам» | проект → тема → задача |

Под ними — строка «Порядок:» с чипами уровней. Чипы перетаскиваются (меняется порядок), удаляются крестиком, добавляются кнопкой «+» из списка. Остаётся хотя бы один чип.

Кнопка «Сохранить как...» открывает окно «Сохранить макет»: «Название» и переключатель «Сделать макетом по умолчанию». Сохранённые макеты показываются отдельной строкой (у макета по умолчанию — звёздочка): клик применяет, крестик удаляет. Макеты личные и свои для каждого вида работ. Макет по умолчанию применяется сам при открытии раздела; без него таблица открывается «По темам».

Как таблица читает порядок:

- Используются **первые два уровня**, задачи всегда внизу. Если первой стоит «Тема», таблица всегда «тема → задачи».
- **Сотрудник, команда и роль**: задача целиком, со всеми часами, относится к одному сотруднику — первому из тех, кто на неё списывал. Часы между людьми здесь не делятся. Точная разбивка по людям — в выгрузке XLSX.
- **Команда** — текущая основная команда этого сотрудника.
- **Проект** — проект Jira, то есть буквенная часть ключа задачи.

### 3.8. Таблица тем и задач

Колонки: «Имя», «Часы», «% от типа» (доля от всех часов отчёта), «Задач», «Сотруд.». Первые три строки раскрыты сразу.

- **Строка темы** — цветной маркер, название, часы, доля, число задач и сотрудников. Раскрытие показывает описание темы от ИИ (курсивом; ключи задач в тексте кликабельны), строку «Сильнее всего:» с пятью самыми крупными задачами темы и ниже — сами задачи. Если описания нет — «AI-описание недоступно».
- **Строка группы** (когда первым уровнем стоит не тема) — промежуточный заголовок с цифрами. На строках второго уровня доля в колонке «% от типа» показывается как 0,0%.
- **Строка задачи** — ключ, название (полностью — во всплывающей подсказке), все часы задачи за период. Клик по ключу открывает карточку задачи.

В таблицу попадают только задачи, отнесённые к темам словаря. Задачи без темы — в кандидатах и в блоке ручной классификации.

### 3.9. Карточка задачи

Открывается справа по клику на ключ задачи — в таблице, в описании темы или в строке «Сильнее всего:».

- Ключ, статус и ссылка «Открыть в Jira».
- Название задачи.
- **«Описание»** — текст из Jira; длинное прячется под «Показать полностью».
- **«Цели»** — фиолетовые метки, если в задаче заполнено поле целей.
- **«Ворклоги за период»** — даты периода и список списаний: кто, дата, часы, комментарий.
- **«Тематическая классификация»** — «Тема: …» и что делали по задаче (текст ИИ). Если тема не определена — «Классификация не определена — назначьте тему вручную», выбор «Выберите тему» и кнопка «Сохранить».

### 3.10. Блок «Требуют ручной классификации»

Сворачиваемый блок под таблицей с числом задач в заголовке. Сюда попадают задачи, на которых разбор ИИ завершился ошибкой. Колонки: «Задача», «Название», «Часы», «Причина» (текст ошибки), «Тема» и кнопка «Назначить».

Выберите тему → «Назначить»: строка тускнеет, кнопка меняется на «Готово». Цифры уже построенного отчёта при этом не меняются. Сейчас при следующем пересчёте ИИ разбирает такую задачу заново и может заменить вашу тему своей.

### 3.11. Словарь тем

Кнопка «Словарь тем» открывает боковую панель с тремя вкладками.

**«Активные»:**
- Ползунок «Порог embedding-матчинга» (от 0,50 до 0,95, по умолчанию 0,78). Чем выше, тем строже сравнение по смыслу: меньше задач сразу попадает в существующие темы, больше уходит на разбор ИИ. Порог общий для всех видов работ и всех пользователей и действует на задачи, которые разбираются заново.
- Кнопка «Создать тему» — окно «Создать тему»: «Название», «Описание», «Цвет», «Порядок».
- Таблица тем: цвет, «Название» (клик — окно «Редактировать тему»), «Описание», «#» (порядок), «Действия»: «Архивировать» (с подтверждением) и «Слить в...» — перенести все задачи темы в другую тему, а эту отправить в архив.
- В окне редактирования есть блок «Алиасы — синонимы темы для embedding-матчинга»: формулировки, по которым задачи будут узнаваться как эта тема. Новый алиас — ввести и нажать Enter или «+»; удалить — крестик на метке.

**«Архивные»** — темы в архиве, кнопка «Восстановить».

**«Кандидаты (N)»** — по каждому кандидату: название, «N ч · M задач», ключи задач и кнопки:
- «Принять» — окно «Принять кандидата»: название и цвет новой темы. Задачи кандидата сразу переходят в новую тему.
- «Слить с» — окно «Слить кандидата с темой»: выбрать существующую тему. Задачи кандидата переходят в неё, а название кандидата добавляется к теме как алиас — похожие задачи дальше будут узнаваться сами.
- «Игнорировать» (с подтверждением «Точно игнорировать?») — задачи уходят в «Другое». При следующем полном пересчёте ИИ может предложить этого кандидата снова; чтобы убрать его насовсем, лучше слить с подходящей темой.

Действия с кандидатами пересчитывают отчёт сразу и без ИИ: описания уже существующих тем сохраняются, у новой темы описания нет до следующего пересчёта. Любая другая правка словаря (создание, редактирование, алиасы, архив, слияние тем) приводит к полному пересбору отчёта при следующей загрузке — все задачи разбираются заново, это может занять несколько минут.

### 3.12. Построение и «Пересчитать»

«Построить первый отчёт» и «Пересчитать» запускают построение с окном «Построение отчёта». Этапы: «Подбор задач», «Классификация задач» (с процентом и строкой «Текущая задача: …»), «Группировка тем», «AI-сводка», «Сохранение». По окончании — «Готово», окно закрывается само. Кнопка «Отмена» останавливает построение; закрытие вкладки тоже его прерывает.

«Пересчитать» строит отчёт заново, даже если он свежий. Задачи, у которых не менялись текст, словарь и настройки ИИ, заново не разбираются — повторный пересчёт идёт быстрее первого. ИИ-сводка, рекомендация и описания тем пишутся заново каждый раз.

### 3.13. PDF для руководства

Кнопка «PDF для руководства» открывает в новой вкладке **отдельную страницу** в светлой теме под печать A4, без меню. Вверху справа — кнопки «Печать / PDF» (диалог печати браузера, там выбрать «Сохранить как PDF» или принтер) и «Закрыть».

Состав страницы: заголовок «Тематический отчёт», период (год, квартал, месяц), «Команды: …», строка «Сформировано: … · Словарь vN · модель · промпт vN», ИИ-сводка с пометкой «AI-сводка» или «Шаблонный нарратив (AI недоступен)», четыре итоговых числа, «Распределение тем», «Топ-3 темы» (описание темы и три самые крупные задачи), «Рекомендация» с «Ожидаемым эффектом». Название вида работ на печатной странице не выводится — подпишите его сами, если отправляете несколько отчётов. Поля, колонтитулы и масштаб настраиваются в диалоге печати браузера.

### 3.14. Выгрузка XLSX

Кнопка «XLSX» скачивает показанный отчёт в Excel. В файле три листа:
- **«Темы»** — «Тема», «Часов», «Доля, %», «Задач», «Сотрудников».
- **«Задачи»** — по строке на каждого сотрудника в каждой задаче темы: «Тема», «Ключ», «Заголовок», «Сотрудник», «Роль», «Команда», «Часы», «Что делали».
- **«Текст»** — ИИ-заголовок, описания тем, рекомендация и ожидаемый эффект.

## 4. Откуда цифры

- **Какие задачи попадают** — задачи, на которые есть списания в периоде и чья категория (своя или унаследованная от родителя) относится к выбранному виду работ.
- **Фильтр команд из шапки** — задача попадает, если она принадлежит одной из выбранных команд (основной или участвующей) **или** на неё списывал человек, который в день списания состоял в одной из этих команд. Группы внутри команды отчёт не учитывает — он всегда по командам целиком.
- **Часы задачи** — **все** списания на задачу в периоде, от всех сотрудников, включая людей из других команд. Периоды участия в команде решают только то, попадёт ли задача в отчёт; часы попавшей задачи считаются целиком. Поэтому итоги могут не совпадать с Аналитикой.
- **Период** — из шапки приложения: квартал или месяц, по дате списания.
- **Тема задачи** — сначала текст задачи (название, цель, текущее поведение, описание, комментарии к ворклогам) сравнивается по смыслу с темами словаря и их алиасами. Если сходство не ниже порога — задача сразу получает тему. Иначе ИИ сам выбирает тему из словаря или предлагает название нового кандидата. На этапе «Группировка тем» похожие названия кандидатов сводятся в одно.
- **Запоминание разбора** — тема задачи хранится и повторно не вычисляется, пока не изменились текст задачи, словарь тем или настройки ИИ.
- **% от типа** — часы строки / все часы отчёта.
- **Сотрудники** — все, кто списывал часы на задачи отчёта или темы.
- **ИИ-сводка, рекомендация, описания тем** — пишет языковая модель при каждом построении по итогам отчёта. Если модель не ответила, ставится шаблонный текст.

## 5. Типовые задачи

### Сценарий А: подготовить квартальный отчёт руководителю

1. В шапке выбрать год и квартал.
2. В шапке выбрать команды, которые входят в отчёт.
3. Открыть «Тематический отчёт», выбрать вид работ → «Применить».
4. Если отчёта ещё нет — «Построить первый отчёт»; если нужен свежий — «Пересчитать». Дождаться окна «Готово».
5. Проверить ИИ-сводку наверху — это главный тезис.
6. Посмотреть «Распределение тем» — пять крупнейших тем и «Другое».
7. Нажать «PDF для руководства» → в новой вкладке «Печать / PDF» → «Сохранить как PDF».

### Сценарий Б: понять, кто работал по теме

1. Найти тему в таблице и раскрыть её — видны описание ИИ, «Сильнее всего:» и задачи.
2. Нажать набор «По сотрудникам» — задачи разложатся по людям, внутри — по темам.
3. Помнить: здесь каждая задача целиком отнесена к одному сотруднику. Точная разбивка часов по людям — «XLSX», лист «Задачи».
4. Кликнуть по ключу задачи — откроется карточка с описанием и ворклогами.

### Сценарий В: добавить новое направление в словарь тем

1. Посмотреть панель кандидатов справа от диаграммы.
2. Нажать «Просмотреть всех кандидатов» — откроется «Словарь тем» на вкладке «Кандидаты».
3. Подходящий кандидат — «Принять» (станет новой темой) или «Слить с» (если это вариант существующей темы).
4. Шум — «Игнорировать».
5. Отчёт пересчитается сразу, без повторного разбора ИИ. Чтобы у новой темы появилось описание — «Пересчитать».

### Сценарий Г: поправить тему, куда ИИ часто относит не те задачи

1. «Словарь тем» → вкладка «Активные» → клик по названию нужной темы.
2. В блоке алиасов добавить формулировки, по которым задачи должны узнаваться как эта тема.
3. Если две темы дублируют друг друга — «Слить в...» у лишней.
4. Закрыть словарь — при следующей загрузке отчёт пересоберётся целиком (может занять несколько минут).

### Сценарий Д: разобрать задачи, на которых ИИ споткнулся

1. Раскрыть блок «Требуют ручной классификации» внизу.
2. Посмотреть «Причину» — часто это временная ошибка модели.
3. Нажать «Пересчитать» — если ошибка была временной, задачи разберутся сами.
4. Для оставшихся выбрать тему → «Назначить».

## 6. Ограничения

- **Построение идёт несколько минут** на больших командах и периодах. Прогресс виден в окне «Построение отчёта»; закрытие вкладки прерывает построение.
- **Автоматический пересбор при открытии** идёт без окна прогресса — страница просто дольше грузится.
- **ИИ может ошибаться.** Доверяйте ИИ-сводке как первой версии, проверяйте по крупным задачам внутри темы.
- **Часы задачи считаются целиком**, от всех сотрудников, даже если задачу взяли в отчёт только из-за одного списания человека из выбранной команды.
- **Группы внутри команды** отчёт не учитывает.
- **Группировка по людям, командам и ролям** относит всю задачу к одному сотруднику; в таблице используются только первые два уровня порядка.
- **Ручное назначение темы** не меняет уже построенный отчёт, а при следующем пересчёте ИИ может его заменить.
- **«Темы» — не «категории».** Тема живёт внутри вида работ и определяется по тексту задачи. Категория ставится в разделе «Категории задач» и определяет, в какой вид работ вообще попадает задача.
- **Печатная страница** рассчитана на A4 в светлой теме; название вида работ на ней не выводится.
- **«Применить» для вида работ** обязательно — без него выбор не срабатывает.

## 7. Частые проблемы

| Симптом | Причина | Что делать |
|---------|---------|------------|
| Вместо раздела сообщение «Тематический отчёт выключен администратором» | ИИ выключен в «Настройки → AI» | Обратиться к администратору; без ИИ раздел не работает |
| Страница долго грузится при обычном открытии | Отчёт строится автоматически: его ещё не было за этот период, либо после построения менялись задачи или словарь | Дождаться; если нужно видеть прогресс — «Пересчитать» |
| ИИ-сводка с меткой «шаблон» или «AI-сводка появится после первого расчёта» | Модель ответила ошибкой, закончилась квота или отчёт не строился | «Пересчитать»; если повторяется — проверить провайдера в «Настройки → AI» |
| Задача попала не в ту тему | ИИ ошибся на похожих формулировках | Добавить алиасы нужной теме, лишнюю тему слить или отправить в архив, затем «Пересчитать» |
| Задача не попала ни в одну тему | ИИ не смог подобрать тему или предложил кандидата | Проверить кандидатов в «Словарь тем» → «Кандидаты» и блок «Требуют ручной классификации» |
| Цифры не совпадают с Аналитикой | Здесь часы задачи считаются целиком от всех сотрудников, группы не учитываются; другой вид работ или период | Сверить период и команды в шапке; помнить о правилах подсчёта (раздел 4) |
| Ручное назначение темы не видно в отчёте | Назначение не меняет уже построенный отчёт | После «Пересчитать» проверить тему в карточке задачи; при необходимости назначить заново |
| Плашка «Устарел» | Показанный отчёт построен до последней правки словаря | Обновить страницу или «Пересчитать» |
| Печатная страница криво ложится в PDF | Настройки печати браузера: масштаб, поля, колонтитулы | В диалоге печати выставить минимальные поля, масштаб «по размеру», убрать колонтитулы |
| Вместо диаграммы «Темы ещё не приняты» | Словарь пуст или все темы в архиве, есть только кандидаты | «Словарь тем» → «Кандидаты», принять подходящие |
| Окно построения долго стоит на одном этапе | Идёт долгий разбор задач или ответ ИИ; либо сбой соединения | Подождать; если не двигается — «Отмена» и запустить снова |
| Нет выбора вида работ, только кнопка «Построить первый отчёт» | Отчёт по этому виду работ получить не удалось, а тем в словаре ещё нет | «Построить первый отчёт» — в окне будет видно, на каком этапе ошибка; другой вид работ можно открыть из Аналитики стрелкой на строке вида работ |

## 8. Связанные разделы

**Откуда приходят данные:**
- **Синхронизация** — без свежей синхронизации задач и ворклогов отчёт работает на старых данных.
- **Категории задач** — категория задачи определяет, в отчёт какого вида работ она попадёт.
- **Настройки → Виды работ** — какие виды работ есть в выборе.
- **Настройки → Категории работ** — какие категории относятся к какому виду работ.
- **Настройки → AI** — провайдер, модель и переключатель «ИИ включён». Без включённого ИИ раздел недоступен.
- **Фильтр команд и период** в шапке приложения.

**Куда уходит результат:**
- **PDF для руководства** — печатная страница в новой вкладке.
- **XLSX** — выгрузка тем, задач с разбивкой по людям и текстов ИИ.

**Соседние отчёты:**
- **Аналитика** — детальный отчёт «команда → роль → сотрудник → вид работ → категория → задача»; стрелка на строке вида работ открывает этот раздел.
- **Дашборд** — в виджете «Нормированные работы» значок «Тематический отчёт» у вида работ открывает этот раздел.
- **Сводка для руководителя** — верхнеуровневые показатели и ИИ-сводка по кварталу.
