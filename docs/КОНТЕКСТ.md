# Контекст JiraAnalysis

## Кто пользователь?

Пользователь не программирует. Общение — коротко, по-русски, на языке аналитика. Технические подробности — по запросу.

## Чем занимается проект?

Анализ данных Jira Data Center и планирование работы команд. Сервис рассчитан на нескольких сотрудников, с разделением данных по командам. Актуальное описание — в корневом и вложенных `CLAUDE.md`; старое описание Jira Cloud в `AGENTS.md` историческое.

## Кто аудитория?

Сотрудники компании и руководители команд. Точный состав аудитории для конкретной доработки уточняется по задаче.

## Как работать с пользователем?

Минимальные законченные изменения, без попутных переделок. Проверять результат перед заявлением о готовности. Соблюдать действующие правила Caveman и Ponytail. Указания текущего пользователя важнее исторической памяти.

## Чего в папке быть не должно?

Материалов других проектов, секретов в документах и случайных выгрузок пользовательских данных. Не включать чужую незавершённую работу в свои коммиты.
